# Portfolio update: StudyLens

This release adds a featured StudyLens AI Study Assistant project card with a **Live Demo** link and a **View Code** link. The older planned AI Study Assistant card has been removed.

## Publish
1. Extract the ZIP.
2. Upload `index.html`, `style.css`, and `script.js` to the **root** of your `Racks-workportfolio.github.io` GitHub repository, replacing the existing files.
3. Commit and wait for GitHub Pages to update.
4. Test both project buttons on desktop and mobile.

The live-demo URL was transcribed from the provided browser screenshot. If the demo button does not open your app, copy the exact URL from your deployed Streamlit browser tab and update the `href` of the **Live Demo** link in `index.html`.
