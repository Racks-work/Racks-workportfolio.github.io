# Jabrial Gardner — Developer Portfolio

A responsive personal portfolio website for **software engineering, artificial intelligence, and game development** internship opportunities.

## Live website

After enabling GitHub Pages for this repository, the expected URL is:

https://racks-work.github.io/Racks-workportfolio.github.io/

The URL works only once GitHub Pages is successfully deployed.

## Features

- Responsive dark-theme design
- Sections for About, Skills, Projects, Education, and Contact
- Filterable project cards (Software, AI, Games)
- Mobile navigation
- Keyboard-accessible controls and reduced-motion support
- No frameworks or build tools required

## Run locally

Open `index.html` in your browser, or use a local development server (such as VS Code Live Server).

## Publish with GitHub Pages

1. Download/extract the portfolio files.
2. In the existing repository `Racks-work/Racks-workportfolio.github.io`, upload `index.html`, `style.css`, `script.js`, and this `README.md` to the repository root (not a nested folder).
3. Commit the changes to your default branch (usually `main`).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**. Select the default branch and `/ (root)`; click **Save**.
6. Wait for deployment to finish, then open the URL above. If the branch or deployment method differs, follow the GitHub Pages status shown in Settings.

## Customize before sharing

- Update the LinkedIn link in `index.html` (currently points to the generic LinkedIn homepage).
- Add a professional email or resume link when ready.
- Replace **In planning** project cards with actual GitHub repository links and demo screenshots when completed.
- Update skill descriptions as your experience grows.
- Review education dates and any personal details.

## Built with

HTML5, CSS3, vanilla JavaScript.

## Important

Project cards are labeled as planned/to publish; they are not claims of finished work. Avoid committing passwords, tokens, private data, or school materials you do not have permission to share.
